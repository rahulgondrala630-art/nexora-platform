# Nexora Platform

> A design-driven operations workspace for turning scattered work into visible, measurable progress.

Nexora is a portfolio-grade full-stack product demonstrating React, TypeScript, Java, Spring Boot, REST API design, testing, product thinking, and delivery discipline in one coherent workspace.

## What it shows

- Calm delivery-health dashboard with momentum signals
- Workstream ownership, priority, progress, and risk states
- Activity timeline for decisions and execution context
- Responsive UI foundations with reusable components
- Spring Boot API foundations, Docker, CI, and product documentation

## Local setup

```bash
docker compose -f ops/docker-compose.yml up --build
```

The interface is designed for a fast reviewer journey: understand the product in 60 seconds, run it locally, then inspect the architecture and tradeoffs.

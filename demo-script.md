# Five-minute demo script

1. Open the dashboard and identify the momentum score.
2. Switch to **At risk** to isolate the workstream that needs a decision.
3. Open a workstream to inspect owner, priority, status, and progress.
4. Open the command palette with `⌘ K` and show the action-oriented navigation pattern.
5. Explain the backend boundary, health endpoint, CI workflow, and staged PostgreSQL milestone.

The demo intentionally uses non-sensitive seeded data. Never add credentials, customer data, or private production URLs to this repository.
